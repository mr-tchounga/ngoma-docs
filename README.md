# ngoma-docs

Legal pages for the Ngoma Android app (`com.shifter.ngoma`), same layout as [boomer-docs](https://github.com/mr-tchounga/boomer-docs).

## Play Console

Privacy policy URL (after GitHub Pages is on):

`https://mr-tchounga.github.io/ngoma-docs/privacy.html`

English: add `?lang=en` (example: `privacy.html?lang=en`). FR/EN toggle is in the header.

## GitHub Pages

1. Push this repo to `https://github.com/mr-tchounga/ngoma-docs`
2. Settings → Pages → Branch **main**, folder **/** (root)
